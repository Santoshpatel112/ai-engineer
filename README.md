# Padho with Pratyush — The AI Engineer Course (10 Week Journey)

## Overview

A free 8-week YouTube series (with bonus modules extending to 10 weeks) designed to land you an AI Engineer role in 2026. Built from analysis of 500+ real AI Engineer job descriptions, 100+ interview reports, and current production stacks used by companies hiring today.

📜 **Full Course Syllabus:** See [docs/roadmap/course-roadmap.md](file:///Users/santoshpatel/ai-engineer/docs/roadmap/course-roadmap.md)

## Goals

- LLM application development & API mastery
- Production prompt engineering & structured output validation (Pydantic)
- Vector databases (ChromaDB, Qdrant) & Embeddings
- RAG Foundations & Advanced RAG (Hybrid Search, Reranking, Contextual Retrieval, RAGAS)
- Agents & Tool Calling (ReAct, LangGraph, Function calling)
- Multi-Agent systems & MCP (Model Context Protocol)
- Observability (LangSmith / Langfuse) & OWASP LLM Top 10 Guardrails
- Full-stack deployment (FastAPI, Docker) & Fine-Tuning basics (LoRA with Unsloth)
- AI System Evaluation & Production readiness
- AI System Design & Interview Preparation
